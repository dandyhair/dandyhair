两个版本的数据存放和迁移情况：

  纯前端版 haircare-finance：
  - 数据存在浏览器 localStorage 里，不是文件，浏览器之间不互通
  - 换电脑不能直接用，需要手动"导出全部数据" → 拿 .json 文件 → 新电脑上"导入全部数据"

  Flask后端版 haircare-finance-server：
  - 数据存在 finance.db 文件里（已生成，20KB），就在项目根目录
  - 整个文件夹拷贝到其它电脑，数据跟着走
  - 新电脑上需要：
    a. 安装 Python 3
    b. 运行 pip install -r requirements.txt（一次性）
    c. python app.py 启动

  拷贝整个 haircare-finance-server 文件夹就行，.db 文件在里面，所有用户的账号和数据都在。

  防火墙还需要放行 5050 端口。请以管理员身份打开 PowerShell 运行：

  netsh advfirewall firewall add rule name="Flask 5050" dir=in action=allow protocol=tcp localport=5050

  另外确认网络是"专用"模式：设置 → 网络和 Internet → WLAN → 点击 HUAWEI-H24 → 改成 专用网络。

  然后手机就能打开了。
