一、系统架构原理
================================================================================

  本系统采用"单后端 + 双前端"架构：

  ┌──────────────────┐
  │  电脑桌面版(index) │──┐
  └──────────────────┘  │
                         ├──→ Flask后端(app.py) ──→ SQLite数据库(finance.db)
  ┌──────────────────┐  │       单文件   单文件
  │  手机/平板(mobile) │──┘
  └──────────────────┘

  核心逻辑：
  - 桌面版(templates/index.html) 和 移动版(templates/mobile.html)
    只是两套不同的"皮肤"，调用的API接口完全一样。
  - 所有数据存储在同一个 finance.db 数据库文件里。
  - 不需要网络、不需要云服务、不需要服务器，就是一个本地Python程序。
  - 同一Wi-Fi下，任何设备访问同一个IP即可共享数据。

  文件结构：
    haircare-finance-server/
    ├── app.py                 ← 后端主程序（路由+API+数据库）
    ├── requirements.txt       ← Python依赖清单
    ├── finance.db             ← SQLite数据库（自动生成）
    ├── templates/
    │   ├── index.html         ← 桌面版前端
    │   ├── mobile.html        ← 移动版前端
    │   └── login.html         ← 登录页（桌面/移动通用）
    └── static/
        └── js/
            ├── app.js         ← 桌面版逻辑
            ├── app-mobile.js  ← 移动版逻辑
            └── chart.umd.min.js ← 图表库

二、环境准备（新电脑首次）
================================================================================

  步骤1：安装Python（如已安装请跳过）

    a) 访问 https://www.python.org/downloads/ 下载最新版
    b) 安装时务必勾选 "Add Python to PATH"
    c) 安装完成后，按 Win+R 输入 cmd 回车，验证：
       python --version
       显示类似 "Python 3.12.x" 即成功

  步骤2：把项目文件夹拷到新电脑

    将整个 haircare-finance-server 文件夹复制到新电脑任意位置，
    例如：D:\haircare-finance-server 或 C:\Users\你的用户名\Desktop\

  步骤3：安装依赖

    打开命令提示符（cmd），进入项目文件夹：
    cd "项目所在路径\haircare-finance-server"

    安装依赖（一行命令搞定）：
    pip install -r requirements.txt

    等待安装完成，无报错即可。

================================================================================
三、启动系统
================================================================================

  1. 打开命令提示符，进入项目文件夹：
     cd "项目所在路径\haircare-finance-server"

  2. 启动：
     python app.py

  3. 看到以下输出表示启动成功：
     * Serving Flask app 'app'
     * Running on all addresses (0.0.0.0)
     * Running on http://127.0.0.1:5050
     * Running on http://192.168.x.x:5050

  4. 保持命令行窗口打开，不要关闭。关闭即停止服务。

四、防火墙 & 网络配置（手机/iPad访问的关键）
================================================================================

  这是决定手机能否访问的核心步骤！必须完成！

  ▶ 步骤A：确认网络为"专用"

    1. 按 Win+I 打开设置 → 网络和Internet → WLAN
    2. 点击已连接的Wi-Fi名称
    3. 将网络配置文件类型从"公用"改为"专用"
    （公用模式下Windows会拦截所有外部设备连接）

  ▶ 步骤B：添加防火墙放行规则

    1. 按 Win 键，输入 PowerShell
    2. 右键 "Windows PowerShell" → 以管理员身份运行
    3. 粘贴以下命令并回车：
       netsh advfirewall firewall add rule name="Flask 5050" dir=in action=allow protocol=tcp localport=5050
    4. 显示"确定"即成功

  ▶ 步骤C：确认电脑IP地址

    1. 按 Win+R 输入 cmd 回车
    2. 输入 ipconfig 回车
    3. 找到"无线局域网适配器 WLAN"下的"IPv4 地址"
    4. 记下这个IP，例如：192.168.3.5

五、访问地址汇总
================================================================================

  假设电脑IP为 192.168.x.x（用上面步骤C查到的替换）：

  ┌──────────┬─────────────────────────────────┐
  │ 设备     │ 地址                            │
  ├──────────┼─────────────────────────────────┤
  │ 本机桌面 │ http://127.0.0.1:5050/          │
  │ 本机移动 │ http://127.0.0.1:5050/mobile    │
  │ 手机     │ http://192.168.x.x:5050/mobile  │
  │ iPad     │ http://192.168.x.x:5050/mobile  │
  │          │ (屏幕大也可用 / 桌面版)          │
  │ 其他电脑 │ http://192.168.x.x:5050/        │
  └──────────┴─────────────────────────────────┘

  注意：所有设备必须连接同一个Wi-Fi！

六、手机/iPad无法打开 —— 完整排查步骤
================================================================================

  按顺序逐一排查，每做完一步就测试一次（用手机浏览器访问）。

  ┌──────────────────────────────────────────────────────────┐
  │ 排查1：确认Flask监听在0.0.0.0                             │
  └──────────────────────────────────────────────────────────┘
    打开 app.py 文件，找到最后一行，确认是：
      app.run(debug=True, host='0.0.0.0', port=5050)
    如果看到 host='127.0.0.1'，改成 host='0.0.0.0' 后重启。

  ┌──────────────────────────────────────────────────────────┐
  │ 排查2：确认端口5050没有被其他程序占用                      │
  └──────────────────────────────────────────────────────────┘
    cmd输入：netstat -ano | findstr ":5050"
    如果有非Python进程在占用，换一个端口（比如5051），
    同时修改 app.py 中的 port 和防火墙规则。

  ┌──────────────────────────────────────────────────────────┐
  │ 排查3：在本机测试网络地址能否访问                           │
  └──────────────────────────────────────────────────────────┘
    在本机浏览器打开 http://192.168.x.x:5050/mobile
    能打开 → Flask配置正确，问题在防火墙或网络                   │
    打不开 → 回到排查1、2

  ┌──────────────────────────────────────────────────────────┐
  │ 排查4：检查网络类型                                        │
  └──────────────────────────────────────────────────────────┘
    设置 → 网络和Internet → WLAN → 点击Wi-Fi名
    确认网络配置文件为"专用网络"（不是"公用"）

  ┌──────────────────────────────────────────────────────────┐
  │ 排查5：检查防火墙规则                                      │
  └──────────────────────────────────────────────────────────┘
    以管理员身份打开PowerShell，运行：
      netsh advfirewall firewall add rule name="Flask 5050" dir=in action=allow protocol=tcp localport=5050

    如果提示"规则已存在"但手机仍无法访问，先删除再重建：
      netsh advfirewall firewall delete rule name="Flask 5050"
      netsh advfirewall firewall add rule name="Flask 5050" dir=in action=allow protocol=tcp localport=5050

  ┌──────────────────────────────────────────────────────────┐
  │ 排查6：检查手机和电脑是否在同一网段                         │
  └──────────────────────────────────────────────────────────┘
    电脑 cmd 输入 ipconfig，查看 IPv4 例如 192.168.3.5
    手机 设置→Wi-Fi→点击已连接的网络，查看IP例如 192.168.3.33
    前三位（192.168.3）必须一致！

  ┌──────────────────────────────────────────────────────────┐
  │ 排查7：检查路由器"AP隔离"                                  │
  └──────────────────────────────────────────────────────────┘
    登录路由器管理界面（通常是浏览器打开192.168.3.1或192.168.1.1）
    找到"AP隔离"或"无线隔离"或"客户端隔离"选项
    确保它是"关闭"状态

  ┌──────────────────────────────────────────────────────────┐
  │ 排查8：放行Python解释器（补充手段）                         │
  └──────────────────────────────────────────────────────────┘
    以管理员身份打开PowerShell：
      netsh advfirewall firewall add rule name="Python" dir=in action=allow program="C:\Users\你的用户名\AppData\Local\Programs\Python\Python312\python.exe" enable=yes

  ┌──────────────────────────────────────────────────────────┐
  │ 排查9：临时关闭防火墙测试（仅测试！测完必须开）               │
  └──────────────────────────────────────────────────────────┘
    设置 → 隐私和安全 → Windows安全 → 防火墙和网络保护
    → 域网络/专用网络/公用网络 → 全部暂时关闭
    手机测试。如果此时能访问 → 说明是防火墙配置问题
    测试后务必重新开启防火墙！

  ┌──────────────────────────────────────────────────────────┐
  │ 排查10：换端口                                             │
  └──────────────────────────────────────────────────────────┘
    Flask默认5000端口可能被别的程序占用（如拼多多打印客户端）
    换一个端口试试，比如5050、8080、8888、3000
    改完 app.py 的 port 后，记得也改防火墙规则的端口号

  ┌──────────────────────────────────────────────────────────┐
  │ 排查11：检查Flask命令行输出                                 │
  └──────────────────────────────────────────────────────────┘
    看Flask运行窗口，手机访问时有没有输出日志？
    有请求日志 → 请求到达了Flask，问题在登录/页面渲染
    无请求日志 → 请求根本没到Flask，问题在网络/防火墙

八、常见问题
================================================================================

  Q: 换了一台电脑，原来的数据怎么带过去？
  A: 复制 finance.db 文件到新电脑的项目文件夹里。

  Q: 多台电脑能同时运行吗？
  A: 只需要一台电脑运行 Flask，其他设备通过浏览器访问即可。
     如果想多台电脑各自独立跑，每台复制一份项目文件夹，但数据互不相通。

  Q: 不用Wi-Fi，用手机热点可以吗？
  A: 可以。电脑连接手机热点，用 ipconfig 查看热点分配的IP即可。

  Q: 系统需要一直开着电脑吗？
  A: 是的。Flask运行在那台电脑上，电脑关机就访问不了了。
     这是本地系统的特性，不依赖云服务。

  Q: 能不能放到云服务器上？
  A: 可以。项目部署到云服务器（如阿里云、腾讯云），修改 host='0.0.0.0'，
     开放安全组端口，就能任何地方通过公网IP访问。
